## Data Storage

**Databases:**
- PostgreSQL 16 (via Alpine container in Docker Compose)
  - Connection: `postgresql+psycopg://skilledguard:skilledguard@db:5432/skilledguard`
  - Client: psycopg[binary] 3.2.3
  - ORM: SQLAlchemy 2.0.36 with Alembic migrations
  - Managed by: `app/database.py` (SessionLocal factory pattern)
  - Models defined in: `app/models.py`

**File Storage:**
- Local filesystem only
- Reports generated in-memory (not persisted to disk):
  - Excel files: Generated by `app/reportes.py::generar_excel()` via openpyxl
  - PDF files: Generated by `app/reportes.py::generar_pdf()` via fpdf2
  - QR codes: Generated by `app/qr.py::generar_png()` via qrcode library
  - Files are streamed directly to client; no persistence

**Caching:**
- None configured - Queries hit PostgreSQL directly each time
- Session-level SQLAlchemy query cache only (default behavior)

## Authentication & Identity

**Auth Provider:**
- Custom JWT-based authentication (in-house implementation)
  - Implementation: `app/security.py`
  - Token creation: Function `crear_token()` uses PyJWT 2.10.1
  - Token verification: Function `usuario_actual()` validates JWT signature and expiration
  - Algorithm: HS256 (HMAC with SHA-256)
  - Expiration: Configurable via `JWT_EXPIRACION_MINUTOS` (default: 60 minutes)
  - Secret: `JWT_SECRET` environment variable (required; no default)

**Password Management:**
- Hashing: bcrypt 4.2.1
  - Hash function: `app/security.py::hashear_contrasena()`
  - Verification: `app/security.py::verificar_contrasena()`
  - Max password length: 72 bytes (bcrypt limitation; enforced in validation)

**Role-Based Access Control (RBAC):**
- Roles defined in `Rol` model (`app/models.py`)
- User-role mapping via `UsuarioRol` junction table
- Role verification: `app/security.py::exige_rol()` dependency function
- Predefined roles:
  - `"Administrador"` (Admin)
  - `"Seguridad"` (Security/Guard)
  - `"Usuario"` (End User)

**Authentication Endpoints:**
- `POST /auth/login` - Login with document ID and password; returns JWT token
- Token passed via: `Authorization: Bearer <token>` header (OAuth2PasswordBearer scheme)
